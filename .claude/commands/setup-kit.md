기존 프로젝트에 Claude Starter Kit을 적용하고 정리/개선한다.

사용자 입력(컨셉·스택 등): $ARGUMENTS

위 입력에서 **컨셉**과 **기술 스택**이 분명하지 않으면, 작업을 시작하기 전에 먼저 묻는다.

## 반드시 지킬 규칙
- `src/assets` 등 사용자가 넣은 이미지·콘텐츠는 "코드에서 안 쓰인다"는 이유로 삭제하지 않는다.
  최대한 사이트에 활용하고, 무엇을 담은 파일인지 모르면 직접 열어(이미지는 Read로 직접 보고) 판단한다.
  그래도 애매하면 삭제하지 말고 사용자에게 묻는다.
- 파일 삭제·대량 변경 등 되돌리기 어려운 작업은 실행 전에 목록·계획을 보여주고 승인받는다.
- 커밋/푸시/배포는 사용자가 명시적으로 허락하기 전에는 하지 않는다.
- 항상 `npm run build`·lint 통과 상태를 유지한다.

## 진행 순서
1. 기존 파일 구조를 분석해 요약한다.
2. starter kit(`CLAUDE.md` / `docs` / `phases` / `scripts` / `verify`)을 적용하고 프로젝트에 맞게 내용을 채운다.
3. 진행 계획을 먼저 제시하고, 승인 후 작업한다.
4. 끝나면 `npm run verify`로 검증한다.
